3‑day outlook

Regional NWP (Open‑Meteo) · local calibration pending history

How this forecast is built. Weather Union's 750+ crowd‑hosted stations report only current conditions — no history or forecast — so the 1–3 day outlook comes from Open‑Meteo's blended physics models (ECMWF/GFS/ICON) for this grid cell. The 0–6h nowcast blends that same model with the live delta at each Gurugram sensor: nowcast(h) = model(h) + (sensor_now − model_now) × local_weight × decay(h), so a station currently running cooler or wetter than the regional grid keeps that offset for the next few hours, tapering out toward the model's own trajectory.

Local weight grows with history. Every scheduled run logs each station's reading. local_weight starts low (0.15) and rises toward 0.9 as ~14 days of logs accumulate per station — and once enough daily cycles are verified, the 3‑day outlook picks up its own local bias correction the same way, gradually leaning on Weather Union's record of this neighborhood rather than the raw regional grid.
